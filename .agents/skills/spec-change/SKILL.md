---
name: spec-change
description: Använd när ett krav, flöde eller en design för löparappen ändras.
---
1. Följ statusreglerna i AGENTS.md och använd GitHub Projects · LOOP Cx (https://github.com/users/simlindahl/projects/2) före, under och efter arbetet. Läs AGENTS.md och aktuellt avsnitt i knowledge/product.md. Beskriv användarens konkreta situation och önskat resultat i en GitHub-issue.
2. Ändra den kanoniska OKF-sidan. Lägg till ett observerbart acceptansexempel och länka från issuen. Bevara YAML-frontmatter med type och relativa länkar.
3. Uppdatera berörda mockuper. Vid ändrat gränssnitt dokumentera vilket underlag Simon har godkänt i design/decision.md. Ett utkast eller ett agentomdöme är inte ett godkännande.
4. Dela arbetet i minsta byggbara ändring. Länka issuen från projektkortet, länka PR och redovisa avvikelser mot beslutat krav. När nästa steg kräver Simons input eller designgodkännande, följ Waiting-reglerna i AGENTS.md.
