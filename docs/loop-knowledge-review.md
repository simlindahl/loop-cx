## Decisions already reflected

Audience: experienced exercisers adapting to career, family, travel and other demands. Explain the complete Core without requiring an app or wearable. Entry under Settings, short introduction, Get started, optional deeper learning. Four-part reading flow. Gym and home choices. Attribution: LOOP by Simon Lindahl. Private reference links and personal race data are excluded.

Core defaults remain two working sets to technical failure, safe stops and recovery adjustments. C1 uses five efforts and exactly 38 minutes, matching the existing product decision. This resolves the private source's conflicting prose about four efforts; it is not a new training-rule change. Optional mobility material is not turned into a mandatory daily routine. Existing app WHOOP integration requirements are unchanged.

## Proposed navigation

Settings → What is LOOP? → Get started (one scrolling reading page, four sections).

The introduction also links to Core workouts and Learn more. Core workouts links to a representative strength card; the eventual complete reader contains all four cards from the guide. Learn more links to Sources. Child pages return to the introduction; the introduction returns to Settings. Settings remains the selected main destination.

The reading page ends with a recap and a return action, not a completion badge. External research links are labelled as requiring internet; all explanations remain local.

## Evidence and editorial limits

Primary sources were checked for resistance training, concurrent training, relative effort, activity recommendations and sleep. References are placed alongside the claims they support in the guide. Research does not validate the exact LOOP system. The guide explicitly separates Core design choices from findings; no silent replacement of the failure default or new weekly quota is proposed.

Home examples are proposed adaptations that preserve movement intent where possible. A safe pulling anchor is a genuine equipment constraint. A row is not presented as identical to a vertical pull. Jumps, mixed work and progression thresholds remain practical Core choices rather than scientifically established minimum doses.

Latest licensing intent: attribution, noncommercial reuse, and commercial enquiries (including PT use of protected material/code) to simon.a.lindahl@gmail.com. **This review does not select a license or grant permissions.** Final terms need a separate decision; a ban on reusing underlying training ideas is not interchangeable with copyright licensing of text and code.
