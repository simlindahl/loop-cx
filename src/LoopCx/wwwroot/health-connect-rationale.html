About this isolated Health Connect test

Debug test · Dedicated emulator only

This test uses synthetic data on the dedicated test emulator. It temporarily writes one running session, one distance record and one heart-rate record. It reads and deletes only records created with the test's own IDs, then checks that they are absent. It does not read other health records or use an account. The test is not a real workout and does not mark a workout as exported.
